# Uso de Inteligência Artificial

## Ferramentas utilizadas

Durante o desenvolvimento utilizei o ChatGPT como ferramenta de apoio.

## Como utilizei

Utilizei IA em várias etapas do desenvolvimento, principalmente para discutir soluções, estruturar a arquitetura, entender melhor algumas regras de negócio e apoiar a implementação dos fluxos.

Também utilizei para revisar código, interpretar erros e logs e encontrar possíveis causas de problemas durante os testes. Isso ajudou bastante a acelerar o desenvolvimento dentro do prazo do desafio.

Durante o processo acompanhei as implementações, executei o código, fiz os testes e procurei entender as decisões utilizadas em vez de apenas aplicar as respostas.

## Minha participação

Organizei o projeto, configurei e executei o ambiente, acompanhei a implementação dos fluxos principais e fui testando cada etapa conforme ela era concluída.

Executei os comandos, testei os endpoints, validei os diferentes perfis e regras de aprovação e fiz ajustes quando encontrei problemas.

Também procurei entender melhor conceitos que ainda não dominava completamente, principalmente autenticação com JWT, Spring Security, organização das camadas e tratamento das regras de negócio.

## Exemplos de uso

1. Tive dúvidas sobre como organizar as regras de aprovação e discuti a estrutura antes de implementar a lógica no service.

2. Durante a autenticação, utilizei IA para entender melhor o fluxo entre JWT, filtro de autenticação e Spring Security.

3. Durante os testes encontrei alguns erros relacionados ao banco de dados e utilizei IA para interpretar os logs, identificar as possíveis causas e chegar mais rápido à correção.

4. No frontend, defini a ideia de uma interface inspirada na identidade visual da Kingspan Isoeste e utilizei apoio da IA para estruturar e revisar as telas. Depois testei os fluxos utilizando os diferentes perfis.

## O que não foi delegado

Não deixei o projeto sendo desenvolvido de forma autônoma sem acompanhamento.

Trabalhei junto com a ferramenta durante o processo, acompanhando o código gerado ou sugerido, executando as alterações, testando os resultados e trazendo os erros encontrados para análise.

Também utilizei o desafio como oportunidade para estudar melhor as tecnologias utilizadas e entender as decisões tomadas durante a implementação.

## Observação final

O uso de IA fez parte do processo de desenvolvimento como ferramenta de apoio para arquitetura, implementação, revisão, diagnóstico de erros e aprendizado.

Todo o uso foi acompanhado durante o desenvolvimento e registrado conforme as regras definidas para o desafio.
